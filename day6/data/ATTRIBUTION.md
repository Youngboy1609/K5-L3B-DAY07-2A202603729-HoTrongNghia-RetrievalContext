# Corpus attribution

Allen B. Downey, *Think Python: How to Think Like a Computer Scientist*, 2nd edition, version 2.4.1, Green Tea Press, 2015. Source: <https://greenteapress.com/thinkpython2/thinkpython2.pdf>.

The source is available under the Creative Commons Attribution-NonCommercial 3.0 Unported license (CC BY-NC 3.0): <https://creativecommons.org/licenses/by-nc/3.0/>. This lab is a noncommercial educational use. The local PDF is the unchanged source; only physical pages listed in `manifest.json` are extracted for the corpus. Extraction uses pdfplumber layout mode, removes page-wide left padding, joins words split by end-of-line hyphenation, and retains paragraph gaps and relative code indentation. The manifest records the stable `document_id`, physical-page character counts and extraction method.
